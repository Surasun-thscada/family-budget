# 💰 คำนวณค่าใช้จ่ายครอบครัว (Family Budget)

หน้าเว็บหน้าเดียว (single file) สำหรับคำนวณว่าเดือนหนึ่งจ่ายอะไรไปเท่าไหร่ และเหลือเงินใช้เท่าไหร่

## ใช้งาน

เปิดที่: https://surasun-thscada.github.io/family-budget/

## ทำอะไรได้

- ใส่ **รายรับต่อเดือน** แล้วดู **เงินคงเหลือ** และ **เหลือใช้ต่อวัน**
- เพิ่มรายการค่าใช้จ่ายได้ไม่จำกัด เลือกรอบการจ่ายเป็น ต่อวัน / ต่อสัปดาห์ / ต่อเดือน / ต่อปี
  แล้วระบบจะแปลงทุกอย่างเป็นยอดต่อเดือนให้เอง (ใช้ 30.4375 วัน/เดือน)
- ปุ่มหมวดที่ใช้บ่อย: ค่าอาหารหมา 🐶, ค่าขนมกิ้ง 🍬, ค่ากินอ้วน 🍜, ค่าน้ำมันรถ ⛽, ค่าของใช้ 🧴
- แสดง % ว่าแต่ละรายการกินเงินไปเท่าไหร่ของรายจ่ายทั้งหมด เรียงจากมากไปน้อย
- แถบเตือนสี: เขียว/ม่วง = ปกติ, เหลือง = ใช้เกิน 80% ของรายรับ, แดง = ใช้เกินรายรับ

## ข้อมูล

เก็บไว้ใน `localStorage` ของเบราว์เซอร์เครื่องที่ใช้เท่านั้น ไม่ได้ส่งขึ้นเซิร์ฟเวอร์
(ถ้าเปลี่ยนเครื่องหรือล้างข้อมูลเบราว์เซอร์ รายการจะหาย)

## พัฒนา

ไม่มี build step — แก้ [`index.html`](index.html) แล้วเปิดไฟล์ในเบราว์เซอร์ได้เลย
ใช้ Tailwind CSS ผ่าน CDN
